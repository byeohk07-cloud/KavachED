# KavachED user guide

## Teachers

1. Create an account with your institution name and keep the generated class code.
2. Open **Data Studio** to add a student and their subject attendance, assessment, assignment, and project details.
3. Use **Students** and **Student 360** to understand risk reasons and add a supportive note or intervention.
4. Upload institution guidance under **Knowledge Base**. Ask questions about it from **Ask KavachED**.
5. Share your class code with students so they can link their own accounts.

## Students

1. Create an account using the class code and your roll number.
2. Your teacher's records appear in **My Overview** and **My Subjects** once entered.
3. Use the attendance calculator, **Study Coach**, and **What-If & Goals** to plan practical next steps.
4. Ask policy questions in **Ask KavachED**. Confirm important decisions with your teacher.
